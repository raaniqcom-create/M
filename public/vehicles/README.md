# صور أنواع السيارات

المعروض الآن **ظلالٌ ظِليّةٌ أحاديّةُ اللون** مرسومةٌ داخل الواجهة
(`components/VehicleArtwork.tsx`) — تُلوَّن رماديّةً حين لا تُختار وخضراءَ حين تُختار،
فلا ملفَّ صورةٍ يُطلب ولا طلبَ شبكةٍ يُهدر.

## لعرض صورٍ فوتوغرافيّةٍ حقيقيّة

1. أسقِط الملفّات هنا بهذه الأسماء بالضبط:

| الملف | النوع | ما يظهر للزبون |
|---|---|---|
| `sedan.png`  | صالون     | سيدان ٤ ركّاب |
| `suv.png`    | دفع رباعي | عالية ٥ ركّاب |
| `pickup.png` | بيك أب    | حمل / بيك أب |
| `van.png`    | فان       | عالية ٧ ركّاب |
| `other.png`  | أخرى      | سيارة صغيرة |

2. ارفع العلَم في `lib/wash.ts`:

```ts
export const REAL_VEHICLE_PHOTOS = true;
```

**المواصفات:** خلفيّة شفّافة (PNG)، عرض ~600px، منظرٌ جانبيٌّ وأنفُ السيارة إلى اليمين،
وهامشٌ متساوٍ حول السيارة كي تتّسق الأحجام. تُصغَّر تلقائياً في الواجهة.
