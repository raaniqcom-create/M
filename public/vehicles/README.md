# صور أنواع السيارات

الرسوم المرفقة `<type>.svg` هي المعروضة اليوم.
ولعرض **صور حقيقية**: أسقِط الملفّات هنا بهذه الأسماء، ثمّ ارفع العلَم
`REAL_VEHICLE_PHOTOS = true` في `lib/wash.ts` (سطرٌ واحد) — فلا تُطلب صورةٌ غيرُ موجودة:

| الملف | النوع | ما يظهر للزبون |
|---|---|---|
| `sedan.png`  | صالون        | سيدان ٤ ركّاب |
| `suv.png`    | دفع رباعي    | عالية ٥ ركّاب |
| `pickup.png` | بيك أب       | حمل / بيك أب |
| `van.png`    | فان          | عالية ٧ ركّاب |
| `other.png`  | أخرى         | سيارة صغيرة |

**المواصفات:** خلفيّة شفّافة (PNG)، عرض ~600px، السيارة بمنظرٍ جانبيّ وأنفها إلى اليمين،
وهامشٌ متساوٍ حول السيارة كي تتّسق الأحجام. تُصغَّر تلقائياً في الواجهة.
