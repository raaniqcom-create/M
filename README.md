# المحطة التقنية — The Technical Station

منصة تتبع محطات الوقود وتوفر المشتقات النفطية في محافظة الأنبار (الرمادي).
تطبيق ويب تقدمي (PWA) بواجهة عربية بالكامل، مُحسّن للهواتف.

## التقنيات

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS** — تصميم أخضر/أبيض، اتجاه RTL
- **Supabase** — قاعدة بيانات Postgres، صلاحيات RLS، تحديثات لحظية، مصادقة
- **Leaflet + OpenStreetMap** — خريطة تفاعلية بدون مفاتيح مدفوعة
- **Web Push (VAPID)** — إشعارات فورية
- خدمة عامل (Service Worker) مكتوبة يدوياً — عمل دون اتصال + إشعارات

## الأدوار

| الدور | الصفحة | الصلاحيات |
|------|--------|-----------|
| السائق / المستخدم | `/` | تصفح المحطات بالقائمة أو الخريطة، بحث، تصفية، تصويت على الازدحام، اشتراك بالتنبيهات — بدون حساب |
| صاحب المحطة | `/owner` | تسجيل المحطة، تفعيل/إيقاف توفر المنتجات، تحديد الازدحام، مشاركة الحالة |
| الإدارة | `/admin` | قبول/رفض طلبات المحطات، إدارة الإعلانات |

## الإعداد المحلي

```bash
npm install
cp .env.local.example .env.local   # ثم املأ القيم
npm run dev
```

### متغيرات البيئة

| المتغير | الوصف |
|---------|-------|
| `NEXT_PUBLIC_SUPABASE_URL` | رابط مشروع Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | المفتاح العام (محمي بـ RLS) |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح الخدمة — للخادم فقط، لإرسال الإشعارات |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | مفتاح VAPID العام |
| `VAPID_PRIVATE_KEY` | مفتاح VAPID الخاص |

توليد مفاتيح VAPID:

```bash
node -e "console.log(require('web-push').generateVAPIDKeys())"
```

## قاعدة البيانات

```bash
# نفّذ محتوى الملف في محرر SQL داخل Supabase
supabase/schema.sql
```

الجداول: `profiles`, `stations`, `station_products`, `traffic_votes`,
`push_subscriptions`, `ads` — بالإضافة إلى العرض `station_traffic_avg`
الذي يحسب متوسط الازدحام لآخر ٣٠ دقيقة عند القراءة.

للتحقق من منطق حساب الازدحام:

```bash
scripts/test-traffic-view.sql   # يحتوي على تأكيدات ويُلغى تلقائياً (rollback)
```

بيانات تجريبية اختيارية: `scripts/seed.sql`

## ملاحظات

- التصويت على الازدحام بالألوان فقط (🟢🟡🔴) — لا تعليقات نصية إطلاقاً، وهذا مفروض على مستوى قاعدة البيانات لا الواجهة فقط.
- صوت واحد لكل محطة كل ٣٠ دقيقة لكل جهاز.
- تحديد صاحب المحطة للازدحام يتجاوز متوسط تصويت المستخدمين.
- المحطة لا تظهر للمستخدمين قبل موافقة الإدارة.
